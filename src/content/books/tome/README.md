# Introduction

**Tome** is a viewer that renders an [mdBook](https://github.com/rust-lang/mdBook)
straight from its source — the `SUMMARY.md` and chapter Markdown — through the
component vocabulary of the *sacred computer*, re-inked onto old paper.

> A book is a machine for reading. This one runs on a sacred terminal, printed
> on parchment.

What you are reading now is the bundled sample book. The table of contents on
the left was parsed from `SUMMARY.md`; this page is `README.md`. Everything is
static HTML — only the sidebar hydrates.

Tome renders the usual Markdown furniture:

- headings, paragraphs, and `inline code`
- ordered and unordered lists
- fenced code blocks
- block quotes, tables, links, and images

Turn the page with the **Next** control below, or pick a chapter from the
contents.

# About

This sample book ships inside Tome as a live demonstration and a fixture. It is
a *suffix* chapter — in `SUMMARY.md` it sits after the `---` separator, past the
numbered guide.

Tome is built on the [sacred computer](https://sacred.computer/) component
library by [Internet Development Studio](https://internet.dev/), and set in
**Mekzantine**, the typeface published at [mek.gallery](https://www.mek.gallery/).

The viewer itself is Astro + SolidJS + TypeScript: zero JavaScript by default,
with only the sidebar hydrated as an island.

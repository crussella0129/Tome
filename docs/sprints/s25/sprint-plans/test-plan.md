## Unit Tests
A test that reads a chapter's Markdown through the Markdown parser runs in
the default (jsdom) environment, as Sprint 24's do; one that touches the
file system or spawns a process begins with `// @vitest-environment node`.
LaTeX in a test is written with `String.raw`, so a backslash is a backslash.
"The reader" in the T-077 tests is `remark-parse` with `remark-gfm` and
T-077's plugin, as Astro composes them.

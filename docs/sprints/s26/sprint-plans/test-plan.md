## Unit Tests
A test that touches the file system, or runs pandoc, begins with
`// @vitest-environment node`. LaTeX in a test is written with `String.raw`.
A tree given to `writePaper()` in a unit test is written out in the test as
pandoc's JSON, so these tests do not run pandoc; the integration tests do.
"The paper's tree" is the tree `readPaper()` gives for `fixtures/latex/paper.tex`,
kept beside the tests as JSON (`src/lib/__tests__/papers/latex-tree.json`)
and compared with a fresh reading in `test_pandoc_latex_tree`, so that a unit
test cannot drift from what pandoc gives; the Typst paper's tree is kept and
compared the same way (`typst-tree.json`, `test_pandoc_typst_tree`).

# Sprint 26 Build Plan

Approved by the user on 2026-11-24 (Plan Mode approval of the Sprint 26
plan). Revised the same day to answer the first plan review
(`critique-round-1.md`) and the second (`critique.md`). The revisions keep
the approved outcome and scope.
They close gaps the reviews found in how pandoc is given a paper's files, in
what pandoc reports as skipped, in how a set-apart formula is carried, in
how an equation's link is made, and in how citations are written; they give
the papers a build and a browser check of their own; and they divide one task
into three (T-089, T-090, T-091), so there are nine tasks where the approved
plan had seven.

Four details were settled in writing the plan out, each from a trial made
after the approval and recorded in the notes of the task it bears on:

- The approved plan's fourth choice would have asked pandoc to hand back what
  it does not know (`raw_tex`). Tried, that setting also makes pandoc hand
  back `\ref`, `\label`, `\input` and the bibliography unread. T-087 instead
  reads a LaTeX paper twice without it: the first reading names each piece
  pandoc skipped and where; the second reads a copy, held in memory, in
  which each such piece is a word Tome knows.
- Not every skipped piece is marked. A drawing or a command that holds words
  takes the mark `[LaTeX not shown]`; a bare command (`\quad`, `\small`) is
  spacing or type, and is named in the build's report without a mark; a
  command Tome knows to be layout is passed over (T-088).
- A paper's own files and pictures are read from the paper's folder and the
  folders within it, which is narrower than "within the library entry's
  folder": LaTeX itself looks for `\input{appendix}` beside the paper.
- A reference to an equation shows its number in brackets, once: `(1)` after
  "see" and inside a pair of brackets alike.

Every behaviour of pandoc that a clause rests on was tried in a scratch
folder before this plan was locked, with `pandoc-wasm` 1.1.0 (pandoc 3.10)
on Node 24, by the author and by the reviewer. "The paper" in the clauses is
the LaTeX fixture of T-087, which is the paper of
`../sprint-research/samples/` with a few lines added. No paper written by
anyone else has been tried; INT-0033 says so.

### T-086: Take a `.tex` and a `.typ` file as kinds of document
- **Intent:** [INT-0033](../../../intents/INT-0033-latex-and-typst-documents.md)
- **Touches:** `scripts/document-source.mjs`, `src/lib/__tests__/document-source.test.ts`
- **Depends on:** (none)
- **Acceptance criterion:** INT-0033 AC1.
- **Success criterion (EARS):**
  - **WHEN** `documentFormat()` is given a path ending `.tex` or `.typ`, in any letter case, **THEN** it **SHALL** return `latex` or `typst`; for `.md` and `.docx` it **SHALL** return what it returns today, and for `.bib`, `.sty`, `.cls`, `.yml` and `.pdf` it **SHALL** return null.
  - **WHEN** `resolveSource()` is given one `.tex` or `.typ` file, **THEN** it **SHALL** return a `document` source whose one document has that format, `opening: true` and `staged: 'README.md'`, whatever the file holds.
  - **WHEN** `resolveSource()` walks a folder, **THEN** a `.tex` file that holds no `\documentclass` outside a comment **SHALL NOT** be among its documents, and a `.typ` file that another `.typ` file in the folder names in `#include "…"` or `#import "…"` (the path read from the naming file's own folder) **SHALL NOT** be among its documents; every other `.tex` and `.typ` file **SHALL** be, ordered, named and given its part as a `.md` file of the same path would be.
  - **WHEN** a folder holds only files left out by the clause above, **THEN** `resolveSource()` **SHALL** throw an Error that names the folder and says that a `.tex` file is read as a paper when it holds `\documentclass`.
  - **WHEN** a path is refused, **THEN** the message **SHALL** name `.tex` and `.typ` among what Tome accepts, both in `ACCEPTED` and in the sentence `refuseAsBook()` adds.
  - **WHEN** a folder holds only `.md` and `.docx` files, or is an mdBook, **THEN** `resolveSource()` **SHALL** return exactly what it returns today.
- **Notes:** the module's opening comment says it reads no document's content; it now reads a `.tex` or `.typ` file's text for this one rule and says so. A comment is a `%` not preceded by a backslash, to the line's end. A file that cannot be read is kept as a document, so that T-092 reports it. Tried by the reviewer: a Typst module brought in by `#import "lib.typ": …` reads, on its own, as an empty tree, so it would be an empty chapter; hence `#import` beside `#include`. An `#import` of a package (`"@preview/…"`) names no file in the folder. `books:add` takes the new kinds through `resolveSource()`; its own words are T-092's. `books:find` lists mdBook folders only, as it does for a Markdown or Word document today, and is not changed.

### T-087: Ask pandoc for a paper's tree, with its own files and what it skipped
- **Intent:** [INT-0033](../../../intents/INT-0033-latex-and-typst-documents.md)
- **Touches:** `scripts/pandoc-read.mjs` (new), `package.json` and `package-lock.json` (add `pandoc-wasm`), `fixtures/latex/` (new: `paper.tex`, `appendix.tex`, `sections/closing.tex`, `figures/triangle.png`), `fixtures/typst/` (new: `paper.typ`, `appendix.typ`, `parts/closing.typ`, `lib/house.typ`, `refs.bib`, `figures/triangle.png`, `uses-a-package.typ`), `src/lib/__tests__/pandoc-read.test.ts` (new), `src/lib/__tests__/papers/latex-tree.json` and `typst-tree.json` (new: the fixtures' trees, kept for the unit tests of T-088, T-089 and T-091 and compared with a fresh reading here)
- **Depends on:** (none)
- **Acceptance criterion:** INT-0033 AC1 (a paper of several files), AC4 (`citeproc`), AC5 (what is skipped is known, a refusal has a reason), AC6 (the source is not changed; nothing outside the paper's folder is read; nothing is fetched).
- **Success criterion (EARS):**
  - **WHEN** `readPaper({ file, format })` is called for a LaTeX paper, **THEN** it **SHALL** resolve to `{ tree, skipped, missing }` where `tree` is pandoc's tree for the paper (its `blocks` and `meta`), read with `from: 'latex'` and no `raw_tex`.
  - **WHEN** the paper, or a file it pulls in, pulls in a file by `\input` or `\include`, or names a `.sty` file, and that file is a regular file in the paper's folder or in a folder within it at any depth, **THEN** the file's content **SHALL** be part of what pandoc reads (the words of `appendix.tex` and of `sections/closing.tex` are in the tree); **WHEN** it is not there, or lies outside the paper's folder, or is reached through a symbolic link that leaves it, **THEN** it **SHALL NOT** be read and, unless its name ends `.sty`, its name as the paper writes it **SHALL** be in `missing`. A file in a folder within the paper's whose name the paper makes with a command of its own (`\newcommand{\sec}[1]{\input{sections/#1}}`), so that no argument in the text names it, **SHALL** be in `missing` too.
  - **WHEN** pandoc's tree names bibliography files ending `.bib` (`meta.bibliography`, one or several), **THEN** each that is a regular file in the paper's folder or within it **SHALL** be given to pandoc and named to it in its `bibliography` option, which takes the place of the paper's own list, and the paper read with `citeproc: true` and the metadata `link-citations: true`, so that each citation is worked out, each cited entry is a link, and a reference list is in the tree; each that is not there **SHALL** be in `missing`; **WHEN** none is there, **THEN** `citeproc` **SHALL NOT** be asked for.
  - **WHEN** pandoc reports that it skipped a piece of a LaTeX paper (`SkippedContent`), **THEN** `skipped` **SHALL** hold one entry for each distinct file, line, column and contents (a piece pandoc reports several times at one place is one entry), with `contents` (the piece as typed), `source` (the file it stood in, as its path from the paper's folder) and `line`.
  - **WHEN** `skipped` is not empty, **THEN** the paper **SHALL** be read again from copies held in memory in which each piece found at the place pandoc gives is replaced by a word of letters and digits (`token`); the tree returned **SHALL** be that second reading's, and an entry **SHALL** have `placed: true` when its word stands in that tree (in `blocks` or in `meta`) and `placed: false` otherwise (the piece was not found, or it stood where pandoc keeps nothing, as before `\begin{document}`). **WHEN** pandoc refuses the copies, **THEN** the first reading's tree **SHALL** be returned and every entry **SHALL** have `placed: false`.
  - **WHEN** a LaTeX paper holds `\today` outside code (`\verb`, `verbatim`, `lstlisting`, `minted`), **THEN** it **SHALL** be treated as a piece pandoc skipped, so that the day the library is built is never written; inside code it **SHALL** stay as typed.
  - **WHEN** `readPaper()` is called for a Typst paper, **THEN** it **SHALL** resolve the same shape, read with `from: 'typst'`, with `skipped` empty; a file the paper, or a file it pulls in, names in quotation marks and pandoc asks for (`#include`, `#import`, and a file read by `csv()` or `read()`) **SHALL** be supplied under the same rule as a LaTeX paper's, its path read from the naming file's own folder, or from the paper's folder when it begins with `/` (the words of `appendix.typ` and of `parts/closing.typ` are in the tree, and a function of `lib/house.typ` is worked out).
  - **WHEN** pandoc refuses a paper (a Typst function or package it does not carry, a file a Typst paper names that cannot be supplied, LaTeX it cannot parse), **THEN** `readPaper()` **SHALL** reject with a `PaperRefused` error whose message holds pandoc's own reason, with the line and column when pandoc gives them, a file named as the paper names it, and no path outside the paper's folder.
  - **WHEN** `readPaper()` has run, however it ended, **THEN** no file on disk **SHALL** have been created, changed or removed, no file outside the paper's folder **SHALL** have been opened, and no connection to the network **SHALL** have been made.
  - **WHEN** a paper asks for more than 200 files or 20 MB of them, or is still asking for new ones after 20 readings, **THEN** no more **SHALL** be supplied, each file still asked for **SHALL** be in `missing` (or, for a Typst paper, the paper refused with pandoc's reason), and `readPaper()` **SHALL** settle.
  - **WHEN** the module is imported, **THEN** `pandoc-wasm` **SHALL NOT** yet be loaded; it is loaded on the first call of `readPaper()` and once in a process.
  - **WHEN** `package.json` is read, **THEN** `pandoc-wasm` **SHALL** be among `dependencies` at an exact version.
- **Notes:** `convert(options, null, files)` keeps its input files in one flat map of names (`src/core.js`), and runs pandoc on that map alone: pandoc can open nothing else, on disk or on the network. ### T-088: Write pandoc's tree as the Markdown of a chapter
- **Intent:** [INT-0033](../../../intents/INT-0033-latex-and-typst-documents.md)
- **Touches:** `scripts/pandoc-to-markdown.mjs` (new), `src/lib/__tests__/pandoc-to-markdown.test.ts` (new)
- **Depends on:** T-087 (the shape of `skipped`, and the fixtures)
- **Acceptance criterion:** INT-0033 AC2 (what a paper holds is shown), AC3 (formulas), AC5 (marks and counts).
- **Success criterion (EARS):**
  - **WHEN** `writePaper({ tree, skipped, format, name, fallbackTitle })` is called (`name` being the paper's own file, as `skipped` names files), **THEN** it **SHALL** return `{ markdown, title, images, leftOut }`, where `markdown` begins with one level-1 heading that is the title: the words of `meta.title` when the tree has one, else `fallbackTitle`. A note inside the title or an author's name (`\thanks`) **SHALL NOT** be in `title` or in the heading; its words **SHALL** be a paragraph directly under the authors' line. A word that stands for a skipped piece **SHALL NOT** be in `title`, the heading or the authors' line.
  - **WHEN** the tree has `meta.title` and its first block is a level-1 heading with the same words, **THEN** that heading **SHALL** be the title and **SHALL NOT** be written twice, and every other heading **SHALL** keep its level; in every other case each heading of the tree **SHALL** be written one level lower than pandoc gives it (a `\section` is `##`), and none lower than level 6.
  - **WHEN** a LaTeX paper's tree has `meta.author` or a `meta.date` that holds words, **THEN** one paragraph in emphasis directly under the title **SHALL** hold the authors, separated by commas, then the date; for a Typst paper no such paragraph **SHALL** be written, since Typst does not print what `#set document(…)` holds and the paper sets its own. **WHEN** the tree has `meta.abstract`, **THEN** a paragraph that is the bold word `Abstract` **SHALL** follow, then the abstract's own paragraphs.
  - **WHEN** the tree holds a paragraph, emphasis, strong text, struck text, inline code, a line break, quoted text, a link, a bullet list, a numbered list (with its first number), a block quotation, a code block (with its language), a rule, or a footnote, **THEN** the Markdown **SHALL** hold the GitHub-flavoured Markdown for it, such that reading the Markdown back with `remark-parse` and `remark-gfm` gives a node of that kind with the same text; raised and lowered text **SHALL** be `<sup>` and `<sub>`; underlined text, small capitals and a span **SHALL** be written as their words, with no count; a definition list **SHALL** be a bullet list whose items begin with the term in bold.
  - **WHEN** the tree holds a table, **THEN** the Markdown **SHALL** hold a GFM table with the same cells and column alignments, its heading row being pandoc's, or the first row when pandoc gives none; a cell that holds several blocks **SHALL** be written on one line with `<br>` between them; a caption **SHALL** be a paragraph directly under the table.
  - **WHEN** the tree holds a figure, **THEN** the Markdown **SHALL** hold its pictures as images and its caption as a paragraph directly under them; each image's address as pandoc gives it **SHALL** be listed in `images` with the place-holder address written for it, for T-092 to settle.
  - **WHEN** the tree holds a block of the paper's own kind (a `Div`: a theorem, a proof, a lemma, an environment pandoc does not know), **THEN** its blocks **SHALL** be written in place, with the name and number pandoc wrote (`**Theorem 1** (Gauss).`) and the proof's end mark.
  - **WHEN** the tree holds a formula, **THEN** its LaTeX **SHALL** be carried on one line: each `%` comment dropped (a `\%` is kept); a line that ended in a comment joined to the next with nothing between, as TeX joins them; and every other line end, with the spaces round it, made one space. **WHEN** the formula is within a line, **THEN** the Markdown **SHALL** hold it between single dollar signs; **WHEN** it is set apart and stands in a paragraph, or inside emphasis or strong text in a paragraph, **THEN** the paragraph **SHALL** be divided so that the formula is a paragraph of its own, written `$$…$$`, which Tome's reader reads as a set-apart formula beside paragraphs and not inside one, the words before and after each a paragraph with their emphasis kept; a set-apart formula in a table cell, a heading, a link or a caption **SHALL** be written within the line.
  - **WHEN** the Markdown is finished, **THEN** it **SHALL** have been read back by `settleEquations()` (`docx-to-markdown.mjs`), so that every formula either comes back from Tome's reader with the LaTeX carried and can be laid out where it stands (`readable()`), or is replaced by `[equation not shown]` and counted in `leftOut` as `{ kind: 'equation' }`.
  - **WHEN** the tree's text holds a dollar sign, a percent sign, an asterisk, an underscore, a bracket, a backslash, a `<` or a line that begins like a list or a heading, **THEN** the built page **SHALL** show that text as the paper has it and it **SHALL** form no formula, emphasis, link, HTML element, list or heading (`It costs $5 … and 50% of it is formulas.` reads back as one paragraph of that text).
  - **WHEN** a link's address is not `http:`, `https:`, `mailto:` or one T-089, T-090 or T-091 writes, **THEN** the link's words **SHALL** be written as text with no link.
  - **WHEN** `skipped` holds a piece, **THEN** it **SHALL** be dealt with by the first of these that fits. (a) It is passed over, with no mark and no count, when it is a layout command of the exported list, by its name, with or without a star, holding no more arguments in braces than the list gives that command (none for most); or is only `\begin{name}` or `\end{name}` with nothing after the name; or is a bibliography piece T-091 reads; or its `source` ends `.sty`. (b) It takes the mark `[LaTeX not shown]` where its word stands in the tree, written so that it is text and never a link, and is counted `{ kind: 'latex', count: 1, detail }` with its name, its line and, when that is not `name`, its file, when it has `placed: true` and is an environment taken whole, a `\begin{name}` with an argument after the name, or a command followed by an argument in braces or square brackets (a layout command holding more groups than the list gives it among them: `\noindent{\bf Keywords:}`, `\color{red}{Red words}`). (c) Otherwise it is counted `{ kind: 'command', count: 1, detail }` with no mark. In every case the word that stood for it **SHALL NOT** be in the Markdown, and the words round it **SHALL** be parted by one space.
  - **WHEN** the tree holds a node of a kind this module has no rule for, **THEN** its words **SHALL** be written as text and `leftOut` **SHALL** count `{ kind: 'node', detail: <the kind> }`; the module **SHALL NOT** throw for any tree pandoc can give.
  - **WHEN** `writePaper()` is given the same tree twice, **THEN** it **SHALL** return the same Markdown.
- **Notes:** the module builds an mdast tree and writes it with `remark-stringify` and `remark-gfm`, as `docx-to-markdown.mjs` does, with formulas carried as that module's place-holders (`placeholders()`, `settleEquations()`); nothing in `docx-to-markdown.mjs` is changed, and the mark `[LaTeX not shown]` is this module's own export. Taking one: `\bibliographystyle`, `\pagestyle`, `\thispagestyle`, `\pagenumbering`, `\vspace`, `\hspace`, `\phantom`, `\hphantom`, `\vphantom`, `\captionsetup`, `\color`, `\rowcolor`, `\cellcolor`, `\geometry`, `\hypersetup`, `\usepackage`, `\documentclass`, `\index`, `\enlargethispage`, `\linespread`, `\graphicspath`. Taking two: `\setlength`, `\addtolength`, `\setcounter`, `\addtocounter`, `\numberwithin`, `\markboth`, `\pdfbookmark`. Taking three: `\addcontentsline`. ### T-089: References to sections, theorems, tables and figures
- **Intent:** [INT-0033](../../../intents/INT-0033-latex-and-typst-documents.md)
- **Touches:** `scripts/pandoc-to-markdown.mjs`, `src/lib/__tests__/pandoc-to-markdown.test.ts`
- **Depends on:** T-088, T-090 (which labels of a formula take a number)
